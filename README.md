## 5. How to Run Locally

### Option A: Direct File Opening
Double-click `index.html` or open in any web browser (Opera, Chrome, Edge, Safari).

### Option B: Local Node.js Server
Run with Antigravity Node or standard Node:
```powershell
& "C:\Users\HCC3\AppData\Roaming\Antigravity\bin\agy-node.cmd" server.js
```
Then visit:
```
http://localhost:3000
```
